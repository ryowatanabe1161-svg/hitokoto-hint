# ひとことヒント 〜かぶったら きえちゃうクマ〜

▶ **あそぶ：https://ryowatanabe1161-svg.github.io/hitokoto-hint/**


みんなで1人の回答者にヒントを出す、オンライン協力ことばゲーム（『Just One』に着想を得たオリジナル作品）。

- 3〜8人推奨（人間2人＋ふーさん🐻でも遊べます）。回答者は人間が順番に担当。
- お題は回答者以外にだけ表示。各自が「ひとことヒント」を1つこっそり書く。
- 同じヒント（ひらがな/カタカナ・全角/半角・長音のちがいは同一視）と、お題を含むヒントは自動で消える。
  チェック画面で、同じ意味のヒントなども手動で消せる（決定はホスト。ホストが回答者のときはヒントを書いた人みんな）。
- 回答者は残ったヒントを見て1回だけ回答 or パス。正解＝カード獲得、パス＝そのカードを失う、
  不正解＝そのカードと山札の次の1枚を失う（最後のカードなら獲得済みから1枚）。
- ふーさん🐻（0〜3人）はヒントだけ出すCPU。お題ごとに用意した連想リストから選ぶので、ときどき かぶります。
- 設定：カード 7/10/13枚、ヒントの制限時間 なし/60/90秒、ふーさんの人数。

## 構成
PeerJS（WebRTC P2P）、ホストのブラウザが進行を管理。部屋コード・招待URL・QR、ニックネームで再接続。
回答者には答え合わせまでお題を送らず、消えたヒントも送りません。

- `index.html` 画面とスタイル / `app.js` 通信・進行・描画 / `logic.js` ルール（正規化・かぶり判定・得点） / `words.js` お題390語とふーさんのヒント候補
- `config.js` ICEサーバー設定（TURNを足す場合はここ）
